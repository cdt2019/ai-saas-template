AI SaaS Template 是一个开源的 Next.js 16 模板，用来做按量收费的 AI 工具。账号、积分、支付、退款、AI 调用、邮件、定时任务和管理后台都已经做好，你只需要专注自己的产品。

克隆下来不用配 key 就能跑，然后把演示工具换成你的功能。

## 包含什么

| 模块 | 内容 |
| --- | --- |
| 账号 | 邮箱密码 + 6 位验证码、验证码找回密码、可选 Google / GitHub 登录 |
| 防刷 | Cloudflare Turnstile、按 IP 和用户限流（存数据库）、拦截临时邮箱 |
| 支付 | Stripe、Creem、Waffo 共用一套接口，另有本地模拟支付；支持一次性积分包、订阅、优惠码和试用 |
| 积分 | 只追加的流水账本，发放幂等，扣费并发安全，退款按比例扣回 |
| 退款 | 用户自助申请，提交时冻结积分，管理员审核后原路退回 |
| AI | 流式文本（任意 OpenAI 兼容接口）、图片和图生视频（fal.ai） |
| 后台 | 概览、用户、交易、订阅、退款、异常、积分流水、AI 调用、定时任务、支付日志、Newsletter、系统检查 |
| 定时任务 | 在代码里登记，带锁、超时、运行历史和失败提醒 |
| Newsletter | 双重确认订阅、一键退订、纯文本群发、分批投递 |
| 监控 | 可选接入 Sentry，上报前去掉敏感信息 |
| 站点 | 首页、价格页、博客、文档、中英文路由、SEO 元数据、深浅色主题 |

## 本地兜底

没有 `.env.local` 时，每个外部服务都有本地替代：

| 服务 | 不配置时 |
| --- | --- |
| 数据库 | PGlite（嵌入式 Postgres），数据在 `.data/pglite`，启动时自动迁移 |
| 支付 | 模拟收银台，付款后照常发积分 |
| AI | 返回模拟结果；提示词里带 `__fail__` 可以测试失败自动退积分 |
| 邮件 | 打印到终端，同时存到 `.data/dev-mail/` |
| 上传 | 存到 `.data/uploads` |

这些只用于开发。模拟支付和默认登录密钥要同时满足「`NODE_ENV` 不是 `production`」和「站点地址是本机」才生效。生产环境必须配置 `DATABASE_URL`，否则会直接报错。

## 目前验证到哪一步

项目还很新，上线前请用自己的账号把依赖的流程走一遍。

| 部分 | 验证方式 |
| --- | --- |
| 登录、积分、后台、定时任务 | 本地服务的端到端测试 |
| Waffo | 假支付平台测试，加一轮真实沙盒 |
| Stripe、Creem | 只跑过假支付平台测试 |
| OpenRouter、fal.ai、R2 | 只跑过 mock |
| 生产环境 | 还没有部署到线上站点 |
