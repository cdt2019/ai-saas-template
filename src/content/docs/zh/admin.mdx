后台地址是 `/admin`，非管理员访问返回 404。怎么成为管理员见[登录与防刷](authentication#管理员)。

## 后台怎么分工

| 层 | 在哪 | 作用 |
| --- | --- | --- |
| 推送 | 铃铛和发给 `ADMIN_EMAILS` 的邮件 | 新问题、新退款申请、任务失败，各提醒一次 |
| 待处理 | `/admin` 顶部 | 现在有哪些事要人管 |
| 处理 | 退款、异常、交易、定时任务 | 具体列表和操作 |
| 排查 | 支付日志 | 一笔交易或一个用户的完整经过 |
| 运营 | 积分流水、AI 调用、Newsletter | 全站活动 |
| 上线检查 | 系统检查 | 缺失或错误的配置 |

## 各个页面

### 概览：`/admin`

「待处理」只列数量大于 0 的项，每行都能点进过滤好的列表：

- 待审核的退款
- 要到平台手动退的退款
- 错误级问题
- 拒付
- 失败的定时任务
- 调度器停了
- 配置错误
- 提醒级问题
- 今天失败的 AI 调用

下面是收入、核心指标、新用户和最近到账。

### 用户：`/admin/users`

搜索和筛选账号。用户详情页有积分、订单、付款、订阅、退款、生成记录、会话和操作日志几个标签页。

详情页可以：

- 调整积分，必须填原因；扣减不能让余额低于 0
- 修改角色
- 封禁（按天数或永久）和解封
- 踢下线
- 删除账号，仅限从未付过款的账号

不能对自己操作，也不能封禁或删除管理员。通过 `ADMIN_EMAILS` 设置的管理员要改环境变量。

### 交易：`/admin/payments`

- **到账**：真实收到的每一笔钱，含续费、退款和拒付状态
- **结账单**：用户发起的每次支付，含未付和过期的

一次性购买两边都有，续费只在到账里，放弃的支付只在结账单里。

### 订阅：`/admin/subscriptions`

按状态查看订阅，可以按邮箱或平台订阅号搜索，按通道和套餐筛选。

### 退款：`/admin/refunds`

审核退款申请：批准、拒绝、平台没退成时撤回冻结，或者重试失败的申请。详见[积分与退款](credits-and-refunds)。

### 异常与对账：`/admin/reconciliation`

问题表，加上按通道和币种汇总的每日报表。问题会去重，状态分为待处理、已解决和忽略。

| 问题 | 级别 | 含义 |
| --- | --- | --- |
| `webhook_error` | 错误 | 回调处理失败 |
| `refund_failed` | 错误 | 退款申请处于失败状态 |
| `balance_mismatch` | 错误 | 余额和流水合计不一致 |
| `paid_without_credits` | 错误 | 已付款的一次性订单没发积分 |
| `over_refunded` | 错误 | 退款超过实付 |
| `missed_webhook` | 提醒 | 靠对账补回了一笔付款 |
| `webhook_rejected` | 提醒 | 签名有效，但不是本站的事件 |
| `reconcile_failed` | 提醒 | 24 小时内查询平台失败 3 次以上 |
| `refund_stuck` | 提醒 | 批准超过 48 小时还没结果 |
| `negative_balance` | 提醒 | 用户余额为负 |

状态类问题（比如余额对不上）条件消失后自动解决。事件类问题由管理员关闭，其中回调错误在平台重试成功后也会自动解决。

### 积分流水：`/admin/credits`

全站每一笔积分变动，只读，顶部汇总跟随筛选。余额卡片是用户手里还没用的积分，也就是你还欠用户的服务。

### AI 调用：`/admin/ai`

调用量、成功率、失败数、卡住的任务、消耗积分，以及各功能的耗时（平均和 P95）。失败记录带平台报错。

### 定时任务：`/admin/jobs`

调度器状态、每个任务的频率和上次结果、带日志的运行历史。可以立即运行、开关任务、修改频率。详见[定时任务](scheduled-jobs)。

### 支付日志：`/admin/payment-log`

只追加的支付流程记录：下单、验签通过的回调、退款操作和结果。按邮箱或任一 ID 搜索，就能看到一笔交易的完整经过。

### Newsletter：`/admin/newsletter`

查看、筛选、导出和移除订阅者，撰写并发送邮件。详见 [Newsletter](newsletter)。

### 系统检查：`/admin/system`

显示哪些配置缺失或有误、迁移有没有跑。详见[部署上线](deployment#系统检查)。

## 列表通用规则

- 工具栏第一行是日期范围和快捷按钮，按 UTC 计算，含首尾两天。
- 日志类列表默认近 7 天，待办队列和实体列表默认全部时间。
- 有搜索词时默认不限日期，老记录也能搜到。
- 搜索、筛选、日期和分页都在网址里，复制链接打开的是同一个视图。
